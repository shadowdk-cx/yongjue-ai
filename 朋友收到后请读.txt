涌觉商贸AI图文视频制作工具 - 完整版使用说明
==========================================

1. 解压本压缩包到任意文件夹（例如桌面）。

2. 安装 Node.js（若未安装）：
   打开 https://nodejs.org 下载并安装 LTS 版本。

3. 启动工具（任选一种）：

   方式 A - 双击启动（推荐）：
   双击文件夹里的「启动工具.command」。
   若提示无法打开，请右键该文件 → 打开。

   方式 B - 用终端启动：
   在解压后的文件夹里打开终端，执行：
   npm install
   npm run dev

4. 启动成功后，用浏览器打开终端里显示的地址（一般为 http://localhost:3000）。

5. 在页面顶部配置栏填入你自己的 Gemini API Key 即可使用。
   API Key 获取：https://aistudio.google.com/apikey

注意：启动后不要关闭终端窗口，关闭后工具会停止运行。
